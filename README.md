# ИС "Закупки-ДР" - Информационная система планирования закупок материалов

Система для автоматизации процесса планирования, учета и контроля закупок материалов для студии мебели "Деревянные решения".

## Описание

**Полное наименование:** Информационная система планирования закупок материалов для студии мебели "Деревянные решения"

**Краткое наименование:** ИС "Закупки-ДР"

### Основные функции

- ✅ Ведение справочников материалов и поставщиков
- ✅ Формирование заявок на закупку материалов
- ✅ Контроль остатков материалов на складе в режиме реального времени
- ✅ Отслеживание статусов заказов поставщикам
- ✅ Анализ расходования материалов по заказам
- ✅ Разграничение прав доступа по ролям пользователей
- ✅ Аналитические отчеты и ABC-анализ материалов

### Цели

- Сократить время формирования заявок на закупку материалов не менее чем на 40%
- Снизить количество случаев дефицита материалов на производстве не менее чем на 50%
- Обеспечить прозрачный учет остатков материалов на складе в режиме реального времени
- Автоматизировать расчет потребности в материалах на основе спецификаций заказов
- Повысить точность планирования закупок и снизить излишние запасы

## Технический стек

### Backend
- **Runtime:** Node.js 18+
- **Framework:** Express.js
- **Database:** PostgreSQL 14+
- **Authentication:** JWT tokens
- **Password Hashing:** bcryptjs
- **API Format:** REST API with JSON over HTTPS

### Frontend
- **Framework:** React 18+
- **Build Tool:** Vite
- **State Management:** Zustand
- **HTTP Client:** Axios
- **Router:** React Router v6
- **Styling:** CSS with CSS Variables

### DevOps
- **Database:** PostgreSQL
- **Container:** Docker & Docker Compose (optional)
- **Server:** Nginx (production)

## Установка и запуск

### Требования

- Node.js 18+
- PostgreSQL 14+
- npm или yarn

### 1. Подготовка базы данных

```bash
# Создание базы данных
createdb zakupki_dr

# Применение схемы
psql zakupki_dr < database/schema.sql
```

### 2. Backend

```bash
cd backend

# Установка зависимостей
npm install

# Создание .env файла
cp .env.example .env

# Редактирование .env с правильными параметрами БД

# Запуск в режиме разработки
npm run dev

# Или запуск в production
npm start
```

Backend будет доступен на `http://localhost:5000`

### 3. Frontend

```bash
cd frontend

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Или сборка для production
npm run build
npm run preview
```

Frontend будет доступен на `http://localhost:3000`

## Использование (Development)

1. Откройте браузер и перейдите на `http://localhost:3000`
2. Зарегистрируйтесь или используйте тестовые учетные данные
3. Начните использовать систему

## Роли пользователей

- **Администратор (admin)** - Полный доступ ко всем функциям
- **Менеджер по закупкам (manager)** - Управление материалами, поставщиками, закупками
- **Кладовщик (warehouse)** - Управление остатками на складе, приходом материалов
- **Директор (director)** - Просмотр и одобрение закупок, просмотр отчетов

## API Endpoints

### Аутентификация
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Получить текущего пользователя

### Материалы
- `GET /api/materials` - Список материалов
- `GET /api/materials/:id` - Получить материал
- `POST /api/materials` - Создать материал
- `PUT /api/materials/:id` - Обновить материал
- `DELETE /api/materials/:id` - Удалить материал

### Поставщики
- `GET /api/suppliers` - Список поставщиков
- `GET /api/suppliers/:id` - Получить поставщика
- `POST /api/suppliers` - Создать поставщика
- `PUT /api/suppliers/:id` - Обновить поставщика

### Заказы
- `GET /api/orders` - Список заказов
- `GET /api/orders/:id` - Получить заказ
- `POST /api/orders` - Создать заказ
- `PATCH /api/orders/:id/status` - Изменить статус заказа

### Закупки
- `GET /api/procurement/requests` - Список заявок на закупку
- `POST /api/procurement/requests` - Создать заявку
- `PATCH /api/procurement/requests/:id/approve` - Одобрить заявку

### Склад
- `GET /api/warehouse/inventory` - Остатки на складе
- `GET /api/warehouse/critical-materials` - Материалы с низкими остатками
- `POST /api/warehouse/receipt` - Записать приход материалов

### Отчеты
- `GET /api/reports/material-usage` - Расход материалов
- `GET /api/reports/inventory` - Остатки
- `GET /api/reports/orders` - Заказы
- `GET /api/reports/abc-analysis` - ABC-анализ

## Требования к производительности

- Время отклика системы на типовой запрос - не более 2 секунд
- Время формирования отчета - не более 5 секунд
- Одновременная работа не менее 15 пользователей без деградации производительности
- Объем хранимых данных - не менее 100 000 записей о материалах и заказах

## Требования к безопасности

- ✅ Хеширование паролей (bcryptjs)
- ✅ JWT токены для аутентификации
- ✅ HTTPS для всех соединений (в production)
- ✅ Разграничение прав доступа по ролям
- ✅ Логирование действий пользователей (аудит)
- ✅ Защита от CSRF и XSS атак
