# 🚀 Быстрый старт - Запуск демонстрации за 5 минут

## Вариант 1️⃣: Чистый запуск (только фронтенд + демо данные)

```bash
# 1. Перейдите в папку фронтенда
cd frontend

# 2. Установите зависимости
npm install

# 3. Создайте файл .env.local
echo "VITE_USE_MOCK_API=true" > .env.local

# 4. Запустите сервер разработки
npm run dev

# 5. Откройте браузер
# http://localhost:3000
```

✅ **Готово!** Система работает с встроенными демонстрационными данными.

---

## Вариант 2️⃣: С backend сервером (полная система)

### Шаг 1: Подготовка базы данных

```bash
# Создайте БД (требуется PostgreSQL)
createdb zakupki_dr

# Примените схему
psql zakupki_dr < database/schema.sql
```

### Шаг 2: Запуск Backend (в первом терминале)

```bash
cd backend

# Установите зависимости
npm install

# Запустите сервер
npm run dev

# Сервер будет доступен на http://localhost:5000
```

### Шаг 3: Запуск Frontend (во втором терминале)

```bash
cd frontend

# Установите зависимости
npm install

# Создайте .env.local (БЕЗ mock mode)
echo "VITE_USE_MOCK_API=false" > .env.local

# Запустите сервер
npm run dev

# Фронтенд будет доступен на http://localhost:3000
```

## 🐛 Решение проблем

### "Порт 3000 уже занят"
```bash
# Используйте другой порт
npm run dev -- --port 3001
```

### "Cannot find module 'express'"
```bash
# Переустановите зависимости
rm -rf node_modules package-lock.json
npm install
```

### "connection refused на 5432"
```bash
# PostgreSQL не запущен
# Если используете Docker:
docker run --name postgres -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres

# Или используйте Demo режим без БД:
echo "VITE_USE_MOCK_API=true" > frontend/.env.local
```

### "Пустая страница или 404"
```bash
# Убедитесь, что используется правильный порт
# Frontend: http://localhost:3000
# Backend: http://localhost:5000
```
