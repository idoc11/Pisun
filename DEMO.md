# Демонстрационный режим - Просмотр сайта без БД

Система содержит встроенный демонстрационный режим, который позволяет просмотреть весь функционал без необходимости подключения к базе данных и запуска backend'а.

## Быстрый старт

### Вариант 1: Через переменные окружения

1. **Создайте файл `.env.local` в папке frontend:**
```bash
cd frontend
cp .env.example .env.local
```

2. **Добавьте строку в `.env.local`:**
```
VITE_USE_MOCK_API=true
```

3. **Установите зависимости и запустите:**
```bash
npm install
npm run dev
```

4. **Откройте браузер:**
```
http://localhost:3000
```

### Вариант 2: Через localStorage (без переключения файлов)

Просто откройте консоль браузера (F12) и выполните:
```javascript
localStorage.setItem('useMockApi', 'true')
```

Затем обновите страницу (F5).

## Возможности в Demo режиме

### ✅ Полностью работающие функции:

- **Аутентификация** - Вход/выход, регистрация (в памяти)
- **Материалы** - Просмотр, создание, редактирование
- **Поставщики** - Полный CRUD
- **Заказы** - Просмотр и изменение статуса
- **Закупки** - Создание и одобрение заявок
- **Склад** - Просмотр остатков и критических материалов
- **Отчеты** - ABC-анализ, использование материалов, инвентарь
- **Фильтрация и поиск** - Работают со всеми данными

### ⚠️ Важные особенности:

1. **Данные в памяти** - Все изменения хранятся только в памяти браузера
2. **При перезагрузке** - Данные вернутся к исходному состоянию
3. **Нет сохранения** - Никаких запросов к серверу не отправляется
4. **Симуляция задержек** - API имитирует реальные задержки (300-500мс)

## Переключение между режимами

### Включить Demo Mode:
```javascript
// В консоли браузера
localStorage.setItem('useMockApi', 'true')
location.reload()
```

### Отключить Demo Mode (требуется запущенный backend):
```javascript
// В консоли браузера
localStorage.setItem('useMockApi', 'false')
location.reload()
```

## Структура Mock API

Mock API находится в файле `frontend/src/services/mockApi.js` и содержит:

- Полные наборы данных для всех основных сущностей
- Методы для CRUD операций со всеми данными
- Фильтрацию и поиск
- Имитацию асинхронных операций с задержками
- Примеры расчетных данных (ABC-анализ, остатки и т.д.)

### Данные сохраняются в памяти объекта `mockData`

Если нужно сбросить данные до исходного состояния - просто обновите страницу.

## Добавление собственных данных в Demo Mode

Если вы хотите добавить больше демонстрационных данных, отредактируйте файл:
```
frontend/src/services/mockApi.js
```

Найдите объект `mockData` и добавьте нужные элементы в массивы.

Пример добавления материала:
```javascript
const mockData = {
  materials: [
    // ... существующие
    {
      id: '6',
      name: 'Новый материал',
      code: 'MAT-006',
      category: 'wood',
      unit_of_measure: 'м³',
      min_stock: 5,
      max_stock: 50,
      unit_price: 3000.00,
      is_active: true
    }
  ],
  // ...
}
```

## Рекомендации для демонстрации

### Для презентации клиенту:

1. **Подготовьте демо данные** - Отредактируйте mockData.js с реальными примерами
2. **Запустите в Demo Mode** - `VITE_USE_MOCK_API=true`
3. **Создайте сценарии** - Подготовьте последовательность действий
4. **Тестируйте локально** - Обновите страницу, если нужны новые данные

### Для разработки фронтенда:

1. **Используйте Demo Mode** - Разрабатывайте UI независимо от backend'а
2. **Тестируйте пользовательские сценарии** - Без необходимости подготовки БД
3. **Проверяйте производительность** - Mock API имитирует реальные задержки
4. **Подготавливайте компоненты** - Пока backend разрабатывается отдельно

## Переход на реальный API

Когда backend будет готов:

1. **Запустите backend сервер:**
```bash
cd backend
npm install
npm run dev
```

2. **Запустите frontend без мока:**
```bash
cd frontend
npm run dev
```

3. **Система автоматически подключится к API** на адресе `http://localhost:5000`

## Решение проблем

### "Данные не сохраняются"
✅ Это нормально в Demo Mode - все хранится в памяти

### "Не могу войти"
✅ В Demo Mode любые email/пароль будут приняты

### "Нужно вернуть исходные данные"
✅ Просто обновите страницу (F5)

### "Хочу использовать реальный backend"
✅ Убедитесь, что backend запущен и используется `VITE_USE_MOCK_API=false`
